# AI Arbitrage Trading Agent

AI-powered trading and arbitrage agent built with Circle Developer-Controlled Wallets SDK.

This project creates blockchain wallets programmatically and prepares an autonomous agent infrastructure for testnet trading, arbitrage detection, and transaction execution.

## Features

- Circle Developer-Controlled Wallet integration
- Programmatic wallet set creation
- Multi-wallet agent architecture
- Smart contract account support
- Testnet-ready trading infrastructure
- Designed for arbitrage and automated trading workflows
